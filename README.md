# Rudi-Foodi
The indie and open-source game, Rudi Foodi!
🐶 Rudi Foodi
Rudi Foodi is a browser-based 3D dog game made with HTML, CSS, JavaScript, Three.js, WebGL, and Web Audio API.
You play as Rudi, a real dog turned chaotic treat-powered legend, running through 20 unique worlds filled with treats, power-ups, clones, zoomies, music, meteors, and absolute nonsense.
🧰 Built With
HTML for the page structure
CSS for UI, title screen, HUD, buttons, credits, and menus
JavaScript for all gameplay logic
Three.js for 3D graphics
WebGL for rendering the 3D world in the browser
Web Audio API for music and sound effects
Pointer Events API for mobile/touch controls
Canvas API for the lava meteor texture
🎮 Features
20 unique levels
dynamic lighting and shadows
touch joystick controls
camera dragging
toggleable Zoomies mode
speed stacks
clone counter and clone removal
treat collection
power-up animations
unique music per level
meteor ending
fly-away ending
credits/lore screen
⚡ Power-Ups
Power-Up	Effect
Blue	Adds permanent speed stack
Yellow	Makes Rudi bigger
Red	Makes Rudi smaller
Rainbow	Spawns 3 clones
Flashing cyan/blue	Spawns 1 clone
